BODY INDEX MASS CALCULATOR
This is a simple Android app developed using Android Studio to calculate Body Mass Index (BMI). The app allows users to input their weight and height, then calculates and displays their BMI along with the BMI category.

Usage:
Open the app.
Enter your weight in kilograms (kg) and height in centimeters (cm).
Tap the "Calculate BMI" button.
The app will calculate and display your BMI value, along with the BMI category based on the result (Underweight, Normal weight, Overweight).

Code Structure:
MainActivity.java – Contains the logic for BMI calculation and interaction with the UI.
activity_main.xml – The layout file that defines the user interface of the app.
strings.xml – Contains all the strings used in the app for better localization.

Libraries and Tools:
Android SDK
Java (Programming Language)
XML (Layout design)
